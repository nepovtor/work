# Эко-Ферма 3D: дорожная карта

Старая игра остаётся на главном адресе; разработка находится в папке 3d/ ветки feature/eco-farm-3d-stage-1. Публичный предпросмотр — preview/eco-3d/ в основной ветке. Корневые файлы действующей игры не заменяются.

## Концепция
Небольшой 3D-двор: игрок учится обращению с отходами через действия, видит результат и постепенно восстанавливает окружение. Без морализаторства и без случайных украшений. Сохраняем бренд «Эко-Ферма».

## Этап 1 — 3D-прототип (начат и реализован)
- Реальные геометрические модели Three.js, сделанные вручную: дом, мастерская, лавочки, деревья, клумбы, фонари, дорожки и пункт приёма.
- Ортографическая камера с вращением жестом и кнопками.
- 6 предметов: газета, картон, PET-бутылка, стеклянная банка, металлическая банка, батарейка.
- 5 категорий приёма, выбор предмета по 3D-модели или через доступный список.
- Анимация сортировки, обратная связь при ошибке, объяснение после правильного ответа.
- Частичное преображение пространства после трёх успешно распределённых предметов.
- Сохранение отдельно от старой игры, адаптивный интерфейс, упрощённый режим при недоступном WebGL.
- Изолированный браузерный сценарий qa.html для проверки основного пути.

Критерий: все шесть предметов можно отсортировать, сохранение переживает перезагрузку, ошибка не тратит ресурсы, после шестого предмета открывается финал.

## Этап 2 — игровая система
- Семидневный маршрут с мягкой мотивацией возвращаться и без штрафа за пропуски.
- Сюжеты про школьную акцию, библиотеку, сбор макулатуры и повторное использование вещей.
- Ресурсы, улучшение двора и история его преображения. Игровой бюджет не изображает физическое превращение бумаги в деревья.
- Задания от жителей, новые участки, события.
- Продуманная и проверенная миграция сохранений ecoFarm_v18 без потери старых данных.
- Указание региона и нюансов местной инфраструктуры сортировки.

## Этап 3 — polish и выпуск
- Связанный набор 3D-моделей, предметные анимации, жители, птицы, погода и свет.
- Сдержанный звуковой дизайн с пользовательским включением.
- Оптимизация WebGL, мобильные испытания, Web accessibility.
- E2E-тесты, вычитка, фактчекинг, UX-аудит и финальное ревью.
- Лишь после успешных проверок релиз вместо старого сайта.

## Архитектура и ограничения
- GitHub Pages — статический хостинг, без серверных секретов.
- Three.js 0.187.0 через import map; на этапе выпуска желателен сборочный Vite с lockfile.
- Первый этап содержит 3D-геометрию, но не художественно изготовленные GLB-модели; это задача финальной арт-проработки.
- Игровое сохранение: ecoFarm3D.stage1.v1. QA использует ecoFarm3D.stage1.qa.
- Сортировка — обучающий пример, а не универсальная инструкция: правила приёма различаются по городам.
- Нет аккаунтов и межустройственной синхронизации.
