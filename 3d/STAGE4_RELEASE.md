# Эко-Ферма 3D — этап 4/4: мобильная приёмка и выпуск

## Что обнаружено и исправлено

1. **Недоступность части категорий на телефоне.** На iPhone две из пяти категорий («Металл» и «Батарейки») прятались за горизонтальным свайпом без явной подсказки. На ширине до 850 px все пять сортировочных кнопок теперь размещаются в сетке **3 + 2** и видны без горизонтальной прокрутки.
2. **Неполные мобильные интерактивные зоны.** Кнопки управления звуком, графикой и камерой имеют минимальную область касания **44 CSS px**. Кнопки категорий не меньше 44 px по высоте в портретной ориентации.
3. **Лишняя работа на каждом кадре.** Ранее `game.js` создавал диагностический объект посредством `polish.diagnostics()` при каждом рендере, чтобы узнать режим экономии. Заменено на дешёвый метод `polish.isEconomy()`.
4. **Кэширование старого JavaScript после выпуска.** Версии `game.js` и `polish.js` обновлены в URL загрузки, чтобы браузер не продолжал использовать предыдущую реализацию.
5. **Проверки не замечали скрытые категории.** Добавлена релизная QA-страница, которая проверяет доступность всех пяти категорий на 320/360/390/430/768 px, контрастные HTML-названия, размеры кнопок, отсутствие горизонтального переполнения, работу WebGL, сохранений и сортировки.

## Автоматическая проверка
- `/3d/qa-release.html`: 12 отдельных испытаний релизного мобильного интерфейса;
- `/3d/qa-art.html`: 12 испытаний 3D-сцены;
- `/3d/qa-glass.html`: 15 испытаний Liquid Glass;
- `/3d/qa-clarity.html`: 8 испытаний чётких 3D-символов;
- `/3d/qa-mobile.html`: 16 испытаний сортировки и мобильного интерфейса;
- `/3d/qa-stage3.html`: 24 испытания всех семи игровых дней.

Итого в полном тестовом наборе **87 проверок**. Скриншоты сохраняются для 320×568, 390×844, 390×844 с уменьшением движения, 844×390 в альбомной ориентации и 1440×900 на компьютере. Chromium работает через software WebGL (SwiftShader), поэтому фактический FPS физического iPhone/Android таким тестом не измеряется.

## Публикация, сохранения и откат
- Полный набор изменений добавляется последовательно PR №8 → №7 → №6 → №5 → `main`.
- `/work/` продолжает перенаправлять на `/work/3d/`.
- `/work/classic/` сохраняет классическую игру с её исходными ключами `localStorage`.
- Ключи `ecoFarm3D.stage1.v1`, `ecoFarm3D.story.v1` и `ecoFarm3D.settings.v1` не мигрируют и не удаляются. Пользовательский прогресс не сбрасывается.
- При проблемах можно восстановить предыдущую версию корневого `index.html` из истории Git или отменить merge-коммит. Выполнять автоматический destructive rollback не следует.

## Ограничения и честная оценка качества
- Текущий двор — стилизованная 3D-миниатюра, а не фотографически точная реконструкция.
- Браузерный glass-слой имитирует подход к Liquid Glass; это не нативный iOS UI material.
- Ручная проверка на физических iPhone и Android, VoiceOver/TalkBack и измерение расхода батареи **отдельно необходимы** для полной production-приёмки.
- Запуск без сервера (через `file://`) не поддерживается из-за ES Modules.
