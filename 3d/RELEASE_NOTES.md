# Эко-Ферма 3D — заметки о выпуске

## Проверка перед объединением

- Семидневная история: 24/24 автоматических проверок на опубликованном предпросмотре.
- Адаптивный интерфейс: 6/6 проверок на ширинах 320, 360, 390, 768 и 1024 пикселя.
- В старой игре по-прежнему доступны локальные данные и сценарии: /classic/.
- В новой игре используется отдельное локальное сохранение, перенос старых данных не выполняется автоматически.

## Проверяем после публикации

1. Адрес /work/ ведёт на /work/3d/.
2. В новой игре есть интерактивный 3D-двор и семь глав.
3. /work/classic/ показывает старую игру с прежними данными.
4. GitHub Pages завершает публикацию успешно.

Если после выпуска обнаружится критический регресс, возврат корневого index.html из предыдущего коммита восстанавливает начальную точку старой версии. Новые файлы 3d/ можно оставить доступными.
